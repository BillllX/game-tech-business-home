# Bill Xu Personal Homepage

A personal landing page for Bill Xu, positioning him as a fintech business leader, AI product engineer, and game-system builder.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Direction

The page highlights three connected themes:

- Business depth in fintech, institutional partnerships, payment channels, loan facilitation, privacy computing, and licensed financial operations.
- Hands-on product engineering across financial systems, full-stack prototypes, WebSocket systems, and AI Agent workflows.
- Game-system thinking through Texas Poker Agent experiments and real-time AI decision environments.

Built with Vite, React, and TypeScript.
